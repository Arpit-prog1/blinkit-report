# 🛒 Blinkit Sales Analysis Dashboard

An interactive **Blinkit Sales Analysis Dashboard** developed using **Microsoft Power BI** to analyze sales performance, outlet characteristics, product categories, customer ratings, and item visibility.

The dashboard provides a comprehensive view of Blinkit's sales data and allows users to analyze performance across different outlet types, outlet sizes, locations, item types, and fat-content categories.

## 📌 Project Overview

This project focuses on analyzing Blinkit's sales data using Power BI.

The dashboard converts raw sales data into meaningful visual insights that help understand:

- Overall sales performance
- Average sales
- Customer ratings
- Total item types
- Outlet establishment trends
- Outlet size performance
- Outlet location performance
- Item category performance
- Fat content distribution
- Outlet type performance
- Item visibility

The dashboard is designed to provide an interactive and easy-to-understand overview of Blinkit's business performance.

---

# 🎯 Project Objectives

The main objectives of this project are:

1. Analyze overall Blinkit sales performance.
2. Identify the highest-performing outlet types.
3. Compare sales across different outlet locations.
4. Analyze sales based on outlet size.
5. Analyze sales by item type.
6. Compare Low Fat and Regular products.
7. Analyze outlet establishment trends.
8. Understand customer rating performance.
9. Analyze total number of item types.
10. Create an interactive business intelligence dashboard.
